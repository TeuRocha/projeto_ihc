### Objetivo do Trabalho?
Retornar um feedback ao usuário para calibrar sua luneta.

### Qual o produto final?
Um sistema de interface simples para recolher a informação da distância que é desejada calibração, e retornar o feedback o mais preciso e rápido possível.

### Quem é o usuário final deste produto?
Os CACs (Colecionadores, atiradores e caçadores), policiais, pessoas com porte de arma.

### O que o usuário recebe de benefício ao usar esse produto?
Menos gasto de munição, consequentemente menos gasto financeiro.
Não se faz necessário conhecimento técnico para calibração, o sistema resolve sozinho.
Aproveitamento do tempo do usuário, menos tempo gasto com a parte chata de atirar, que é calibrar.

### Quais as funcionalidades da ferramenta (visão do usuário)?
Sistema de cadastro e login do usuário, tela para receber do usuário a distância desejada para calibrar, e a tela de feedback.
